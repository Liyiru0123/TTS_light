# P3-W03 TinyTTS 指标与术语说明

> 工作包：`P3-W03 TinyTTS`
> 说明版本：1.0
> 建立日期：2026年8月20日
> 用途：逐项定义本工作包评价指标与专用术语的中文名称、机器字段、评价对象、预处理、公式或判定步骤、聚合范围、数值方向、阈值作用、是否进入 `is_fully_correct` 及已知局限。总结报告、结果目录 README 和规范能力样例均引用本文件。

## 1. 术语表

| 术语 | 唯一含义 | 备注 |
|---|---|---|
| 文本—语音单元 | 从 P1 源语句按字符对齐切分出的约 1—3 秒片段，含文本、mel、token 边界、T_valid | DATA-SPG-001 派生 |
| T_valid | 该单元的有效 latent 帧数，由 alignment projection 决定 | 前缀 `[0, T_valid)` |
| T̂ | Duration Predictor 预测时长之和 $\sum_i \hat{d}_i$ | 推理时由模型决定 |
| T_max | 最大窗口 = 64 latent 帧 | 教学系统约定，非固有长度 |
| duration_overflow | $\hat{T} > 64$ 的显式失败状态 | 不静默截断 |
| alignment projection | mel→latent 的确定性投影约定（nominal-bin，路线 A） | 非真实 receptive field |
| nominal-bin convention | latent 帧 $j$ 指派 bin $[4j, 4(j+1))$，中心 $c_j = 4j+2$ | 时间压缩比 4 |
| zero-latent-duration | 某 token 区间内无 latent 帧中心落入，$d_i=0$ | 压缩分辨率损失，非对齐错误 |
| posterior mean | 冻结 P3-W02 VAE 的 $\mu$，训练 target $x_1$ 的来源 | 非推理路径模块 |
| linear CFM | 线性路径流匹配，$x_t=(1-t)x_0+tx_1$，$v_\theta \approx x_1-x_0$ | 非完整 OT-CFM |
| velocity field | 速度场网络 $v_\theta(x_t, t, c)$ | 依赖 $(x_t,t,c)$ 三者 |
| frame-wise condition | $y = x_t + C_{64}$，共享 $W: 64\to80$ | 输入端一次注入 |
| ground-truth duration（真值时长，机器字段缩写 gt） | 由 alignment projection 得到的真值时长 $d_i$；训练与受控评估时可用，推理时不可用 | Gate B 使用；原称 oracle duration |
| predicted duration | Duration Predictor 输出的 $\hat{d}_i$ | Gate C / I001 使用 |

> **术语约定（2026-08-20，教师决定）**：统一使用 ground-truth duration（真值时长）表达原“oracle duration”，代码与机器字段用缩写 `gt`；文档、证据文件与示例音频命名均不再出现 oracle。
| text ON / OFF / shuffled | 条件消融三态：正确文本 / 零条件 / 乱序文本 | 相同时长规划下比较 |
| 回译 CER | 冻结 TinyASR 对生成波形的字符错误率 | 可懂度代理 |

## 2. 指标定义

### 2.1 回译 CER（`test_cer` / `asr_cer`）

- **中文名称**：回译字符错误率
- **机器字段**：`test_cer`（测试集）、`asr_cer`（固定样例）
- **评价对象**：生成波形 → 冻结 TinyASR 回译文本 vs 单元参考文本
- **预处理**：生成 mel → 裁剪到 $4\cdot\hat{T}$ 帧 → 冻结 HiFi-GAN 波形 → 64 维 log-mel（n_fft=512, hop=256, fmin=40, fmax=8000）→ 逐通道 z-score → TinyASR 贪心解码
- **公式**：$\text{CER} = \dfrac{\text{edit\_distance}(\text{ref}, \text{hyp})}{|\text{ref}|}$
- **聚合范围**：测试集全部单元（或固定样例集）的字符错误数之和 / 参考字符数之和
- **数值方向**：越小越好
- **阈值作用**：`MODEL-SPG-001` 生成 CER − 冻结链基准 CER（直接解码后验均值）≤ 0.10（v1.1 修订，理由见测试计划 §5.1）；绝对 CER 仅作报告项
- **进入 is_fully_correct**：是（CER == 0 且无硬削波）
- **已知局限**：同源 ASR（P2-W05）对同源合成语音近乎饱和，CER 低不代表自然度或真实语音可懂度；单声、有限模板，不可外推

### 2.2 时长相对误差（`mean_rel_error`）

- **中文名称**：时长相对误差
- **机器字段**：`mean_rel_error`
- **评价对象**：预测时长 $\hat{T}$ vs 真值 $T_{\text{valid}}$
- **公式**：$\dfrac{|\hat{T} - T_{\text{valid}}|}{T_{\text{valid}}}$，对单元取均值
- **聚合范围**：测试集全部单元
- **数值方向**：越小越好
- **阈值作用**：`MODEL-SPG-002` 均值 ≤ 0.05
- **进入 is_fully_correct**：否（单独指标）
- **已知局限**：仅衡量总时长，不衡量逐字符时长分配

### 2.3 预测 vs 真值 CER 差（`cer_gap`）

- **中文名称**：时长误差 CER 差
- **机器字段**：`cer_gap`
- **评价对象**：CER(predicted duration) − CER(ground-truth duration)
- **公式**：$\text{CER}_{\text{pred}} - \text{CER}_{\text{gt}}$
- **聚合范围**：测试集全部单元
- **数值方向**：越小越好（理想为 0）
- **阈值作用**：`MODEL-SPG-002` ≤ 0.05
- **进入 is_fully_correct**：否
- **已知局限**：依赖 ground-truth duration 的 CER 作为下界

### 2.4 零时长率（`zero_duration_rate`）

- **中文名称**：零 latent 时长率
- **机器字段**：`zero_duration_rate`
- **评价对象**：$d_i^{\text{latent}}=0$ 的 token 占比
- **公式**：$\dfrac{\#\{i: d_i=0\}}{\#\text{tokens}}$，只在 $J_{\text{valid}}$ 上统计
- **聚合范围**：训练/测试单元
- **数值方向**：教学现象，无阈值（越低表示压缩分辨率越充分）
- **阈值作用**：无（记录现象）
- **进入 is_fully_correct**：否
- **已知局限**：是表示压缩分辨率不足的诚实信号，不是对齐错误

### 2.5 overflow 率（`overflow_rate`）

- **中文名称**：时长溢出率
- **机器字段**：`overflow_rate`
- **评价对象**：$\hat{T} > 64$ 的单元占比
- **公式**：$\dfrac{\#\{\hat{T}>64\}}{\#\text{units}}$
- **聚合范围**：测试集全部单元
- **数值方向**：越小越好
- **阈值作用**：记录现象，无硬阈值（教学边界）
- **进入 is_fully_correct**：否
- **已知局限**：overflow 单元不计入 CER（显式失败）

### 2.6 条件贡献（`ablation`）

- **中文名称**：文本条件贡献
- **机器字段**：`cer_text_on`、`cer_text_off`、`cer_shuffled`
- **评价对象**：相同时长规划下三态 CER
- **判定**：`cer_text_on < cer_text_off` 且 `cer_text_on < cer_shuffled`
- **聚合范围**：测试集全部单元
- **数值方向**：text ON 的 CER 应最低
- **阈值作用**：`MODEL-SPG-001` 条件贡献成立
- **进入 is_fully_correct**：是（条件贡献是核心断言）
- **已知局限**：ground-truth duration 本身含文本 timing 信息，消融的是“相同时长下的内容条件”

### 2.7 可训练参数量（`trainable_params`）

- **中文名称**：可训练参数量
- **机器字段**：`trainable_params`
- **评价对象**：TinyTTS 可训练参数（Text Encoder + Duration + Length Regulator + frame-wise W + 1D U-Net）
- **公式**：$\sum \prod \text{shape}$（可训练参数）
- **数值方向**：受上限约束
- **阈值作用**：`RES-SPG-001` < 1,000,000
- **进入 is_fully_correct**：否
- **已知局限**：不含冻结 VAE/HiFi-GAN/ASR 参数

### 2.8 训练墙钟（`wall_seconds`）

- **中文名称**：训练墙钟时间
- **机器字段**：`wall_seconds`
- **评价对象**：I001 正式训练端到端墙钟
- **数值方向**：受上限约束
- **阈值作用**：`RES-SPG-001` ≤ 3,600 秒
- **进入 is_fully_correct**：否
- **已知局限**：CPU 8 线程，含数据加载与评价

### 2.9 峰值 RSS（`peak_rss_bytes`）

- **中文名称**：峰值常驻内存
- **机器字段**：`peak_rss_bytes`
- **评价对象**：训练进程峰值 RSS
- **数值方向**：受上限约束
- **阈值作用**：`RES-SPG-001` ≤ 2,684,354,560 字节
- **进入 is_fully_correct**：否
- **已知局限**：观察值，非严格上限

### 2.10 HiFi-GAN RTF（`vocoder_rtf`）

- **中文名称**：声码器实时率
- **机器字段**：`vocoder_rtf`
- **评价对象**：HiFi-GAN 波形生成耗时 / 生成音频时长
- **数值方向**：越小越好（<1 为实时）
- **阈值作用**：`MODEL-SPG-001` ≤ 1.0
- **进入 is_fully_correct**：否
- **已知局限**：仅测声码器，不含 CFM 采样

## 3. 不可外推范围

1. 同源 ASR 回译 CER 不代表真实语音可懂度或自然度；
2. 单声（慧慧合成）、有限模板、同源数据，不可外推多说话人、开放文本、真实录音；
3. linear CFM 非完整 OT-CFM，不宣称概率运输最优；
4. 64 帧容器是教学系统约定，非 TTS 固有输出长度；
5. 零时长率是压缩分辨率信号，不是对齐错误；
6. 条件贡献消融基于 ground-truth（真值）时长，不覆盖时长规划错误场景。
