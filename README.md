# 多模态数据处理与应用 · 课程最小系统（gitee 安装包）

> 版本基：P3-W05 六类模型集成验收（2026-08-22 教师确认）
> 仓库：https://gitee.com/solehome2/mini_multimodal.git

## 一、背景说明

本包是《多模态数据处理与应用》课程的配套**教学用最小系统**：用可控数据规模（1,720 场景 / 11,163 问答 / 5,160 生成条件）和微型模型（参数 4—62 万）把"多模态数据生成 → 逐类模型训练 → 集成推理"全链路做成**可在学生笔记本（CPU）上复现**的课堂实验。

包内包含三类内容：

1. **可运行代码**：`src/mini_multimodal/`（数据生成、训练、推理、评价、治理）+ `configs/` + `scripts/`；
2. **教师认可的预训练权重**：9 个（`results/` + `models/external/`，清单与 SHA-256 见 `manifest_sha256.md`，运行方式见 `运行手册.md`）；
3. **最小运行时种子** `seed/`：第一次课 Notebook 直接可用的少量数据与样例（详见 `运行手册.md` 第 4 节）。

覆盖 6 类微型模型任务：

| 任务 | 模型（包内版本） | 输入 → 输出 |
|---|---|---|
| 图文分析/接地 | TinyVLM（P2-W03） | 图像＋问题 → 答案/目标位置 |
| 语音识别 | TinyASR（P2-W05 I002） | 语音 → 中文文本 |
| 文生图 | TinyImageLDM（P2-W04 I004/control） | 中文描述 → 图像 |
| 视频分析 | TinyVideoMLLM（P3-W01 I003） | 视频＋问题 → 答案/运动描述 |
| 语音重建＋文生音 | TinySpeechVAE（P3-W02 I002）+ TinyTTS（P3-W03 I004） | 语音→潜表示→语音；文本→语音 |
| 文生视频 | TinyT2V（P3-W04 I008，运动模块） | 含运动的中文描述 → 8 帧视频 |

**运行环境**：Python **3.12**（本包在其上完整验证；`torch` CPU 版，Windows 数据生成需系统自带 "Microsoft Huihui Desktop" 语音）。依赖清单见 `docs/requirements.txt`，安装、数据生成、逐模型训练与推理的完整操作见 **`运行手册.md`**。

> 本包的能力测试与对/错样例（含嵌入媒体的人工查看版）属于本地测试结果，**不随本包上传**。
